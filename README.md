🎮 Game Overview

Echoes of Time is an ambitious open-world survival horror game set in a post-apocalyptic world. You awaken from cryogenic sleep in an abandoned laboratory, emerging into a vast 4km x 4km world filled with danger, mystery, and the undead. The game combines exploration, survival mechanics, crafting, questing, and intense combat in a richly detailed environment.
